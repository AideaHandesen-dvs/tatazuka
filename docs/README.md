## demo.gif — トップに貼っているデモ

- **撮り方**：佇かを映した端末（デモ機）を別のスマホ（撮影機）で**外から手持ち撮影**する。
  画面録画ではなく端末ごと撮るのが肝＝「透明な箱が机の上にある」体感は端末の実体ごと写さないと伝わらない。
  野外・自然光・背景に緑などの特徴物（カメラ背景に透けて「箱」だと分かる）。
- **デモ機の準備**：信頼された証明書（mkcert CA 導入済み端末）で `https://<host>:8443/` を開き、
  「ホーム画面に追加」→ そのアイコンから起動（URL バー無し全画面・`?hud=off` 既定。client/README.md 参照）。
  ※ 現行の demo.gif はあえて URL バー付きで撮っている（「ただのブラウザで動く」設計の証明・README §10）。
- **絵コンテ**（10秒・ループ前提）：佇む → カメラを回り込ませて視差で覗き込み（目が追う）→ つつく/なでるで反応。

### 動画 → GIF の変換レシピ（実際に使ったもの）

ソースは 1080p/60fps・10秒の `.mp4`。GitHub の README で安全に表示できるサイズ（10MB 未満目安）に落とす。

```sh
# 320px 幅・10fps・128色・2-pass パレット。被写体を大きく見せるため軽くクロップ＋頭0.4秒トリム。
# crop=w:h:x:y は元動画に合わせて調整（端末を画面いっぱいに）。
ffmpeg -ss 0.4 -i src.mp4 \
  -vf "crop=940:1760:70:80,fps=10,scale=320:-1:flags=lanczos,split[a][b];[a]palettegen=stats_mode=diff:max_colors=128[p];[b][p]paletteuse=dither=bayer:bayer_scale=5" \
  docs/demo.gif
```

- サイズが大きすぎたら順に効くツマミ：`fps` を下げる → `scale` 幅を縮める → `max_colors` を減らす。
- 320px/10fps/128色で約 9MB（10秒）。これ以上長尺なら fps か尺を削る。
- 単色化したいなら `paletteuse` の前に `hue=s=0` を挟む（現行はカラーのまま）。
