# characters/ — ゴースト（差し替えできる人格）

ここは佇か本体にとっての「ゴーストの住処」。伺かの `ghost/<名前>/` を **1 ゴースト＝1 テキスト
ファイル**に簡略化したもの。本体（エンジン）と人格（このファイル群）を分け、人格だけ差し替えられる。

## 仕組み

- `persona-llm.js` が `TZ_CHARACTER=<名前>` を見て `characters/<名前>.txt` を読み、LLM の
  system プロンプトに使う。**未設定なら `tatazuka`**。
- ファイルに書くのは**人格文だけ**。出力契約（厳格 JSON `{text, mood}`・mood 語彙）は本体側＝
  `persona-llm.js` の `OUTPUT_RULE` が握る。**ゴーストを差し替えても JSON 契約は不変**。
- 読めない／名前が不正なら、組み込みの佇か（`DEFAULT_CHARACTER`）にフォールバック。
  **ゴーストを全部消しても佇かは喋る**（プログレッシブ・エンハンスメント）。

## 使う

```sh
TZ_LLM=ollama TZ_LLM_MODEL=qwen2.5:3b node server/serve.js                  # 既定＝佇か
TZ_CHARACTER=shitsuji TZ_LLM=ollama TZ_LLM_MODEL=qwen2.5:3b node server/serve.js  # 執事に差し替え
```

`TZ_CHARACTER` は LLM が有効（`TZ_LLM` 設定時）のときだけ効く。ルールベース（LLM オフ）の台詞は
`persona.js` の手書き表が握っており、そちらは別の継ぎ目（佇か固定）。

## 足す

`characters/<名前>.txt` を置くだけ（名前は英数・`_`・`-`）。テンプレは既存ファイルを写す：

```
あなたは（このゴーストが何者か）。…端末の中にいて…という存在。

# 基本設定
- 名前：…
- 一人称：…
- 二人称：…

# 性質・口調
- （性格・口調）
- 短く言う。1文、長くても2文。説明や前置きはしない。   ← これは外さない（台詞が長いと佇からしくない）
```

## 同梱ゴースト

| 名前 | 人物 | 一人称/二人称 | トーン |
|---|---|---|---|
| `tatazuka` | 佇か（既定） | 俺 / お前 | ぶっきらぼうで皮肉屋、素直じゃない |
| `shitsuji` | 老執事セバス | わたくし / ご主人様 | 慇懃・丁寧語、主人を気遣う |
| `imouto` | 妹分ひな | あたし / おにいちゃん | 明るくハイテンション、世話焼き |

執事・妹は「同じ状況・同じ JSON 契約でも、声色だけ丸ごと変わる」ことを示すサンプル。
